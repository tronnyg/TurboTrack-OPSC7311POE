# TurboTrack

Welcome to **TurboTrack**, an innovative Android application designed to revolutionize productivity and teamwork. Leveraging Firebase Firestore and advanced technology, TurboTrack offers a unique blend of features to enhance your work experience. This README will guide you through TurboTrack's capabilities, setup instructions, and contribution guidelines.

## Overview

TurboTrack is a cutting-edge productivity app that combines task management, gamification, and seamless integrations to optimize your workday. With features such as the Pomodoro Technique, Turbo Boost, and race-themed notifications, TurboTrack turns productivity into an engaging journey.

### Key Features

- **Gamification Elements**: TurboTrack transforms work into an exciting experience with race-themed tasks, badges, rewards, and leaderboards.
- **Pomodoro Technique Integration**: Enhance focus with a customizable Pomodoro Timer for work sessions and breaks.
- **Turbo Boost**: Add a competitive edge to project progress with our unique Turbo Boost feature.
- **Google Calendar Sync**: Seamlessly integrate with Google Calendar for task and deadline management.
- **Team Leaderboard**: Monitor and compare team progress with tracked hours and accountability features.
- **Automated Notifications**: Stay motivated with race-themed alerts and reminders.
- **Holiday Mode**: Maintain productivity streaks during breaks, ensuring a smooth return to work.

## App Requirements

### User Authentication

- **Log In**: Users can log in with their email address and password or via Google account.
- **Registration**: New users can register using their email address and password or through Google account integration.

### Task Management

- **Create Tasks**: Users can create and manage personal tasks with details like Name, Description, Status, and Color.
- **Team Tasks**: For collaborative tasks, users can assign or remove members and manage task details.

### Adding Friends

- **Search and Connect**: Users can search for others by name and add them to tasks upon acceptance. Activity visibility is broad and respects privacy.

### Project Management

- **View Projects**: Detailed project views include client information, members, notifications, and attachments.
- **Edit Projects**: With permissions, users can edit project details, manage tasks, and update attachments.
- **Create Projects**: Users can create new projects with client details, members, tasks, and attachments.

### Pomodoro Timer

- **Customizable Timer**: Use a Pomodoro Timer with adjustable settings for focus length, break length, and Pomodoro sessions before a long break.

### Application Settings

- **Customization**: Users can adjust notifications, language, themes (including dark mode), and alerts.
- **Support**: Access FAQs and chatbots for assistance.

### User Profile

- **Profile Page**: View and edit user stats, activity timeline, and friends.

### Gamification

- **Streaks and Badges**: Earn badges, rewards, and achievements for engagement and task completion.
- **Leaderboards**: Compete on leaderboards and participate in challenges.
- **Progress Tracking**: Track and visualize your progress through gamification elements.

### View Team Report

- **Summary Reports**: Generate and view reports of work hours by day, week, and month, filtered by projects.
